
PiperSR 独立超分功能开发文档（独立模式）

项目：iOS 视频处理 App（testping 分支）
功能：2x 超分辨率（独立模式，不与补帧串联）
适用系统：iOS 16.0+
文档版本：v1.0
最后更新：2026-10-16

1. 概述

1.1 功能定位

本 App 提供两种互斥的视频处理模式，用户每次处理只能选择一种：

1. 补帧模式（Frame Interpolation）：使用 RIFE Lite，提升帧率（2x / 4x），让画面更流畅。
2. 超分模式（Super Resolution）：使用 PiperSR，提升分辨率（2x，如 720p → 1080p），让画面更清晰。

不提供“超分+补帧”的组合模式，避免双重 AI 推理导致的内存爆炸、发热过载和画质伪影。

1.2 模型参数

· 参数量：453K
· CoreML FP16 包体：928 KB
· 放大倍数：2x
· PSNR (Set5)：37.54 dB
· 架构：6 个残差块，64 通道，SiLU 激活，PixelShuffle
· ANE 推理延迟：约 22.5 ms（640×360 → 1280×720）
· 许可证：代码 AGPL-3.0，权重 PiperSR Model License（个人侧载使用符合许可范围）

4. 管线集成

4.1 修改 VideoPipeline 支持双模式

在 VideoPipeline.process() 中增加 mode 参数，根据模式决定是否调用 PiperSR 或 RIFE：

```swift
func process(
    inputURL: URL,
    outputURL: URL,
    mode: PipelineMode,
    progress: @escaping (Double, ProcessingStage) -> Void,
    completion: @escaping (Result<URL, Error>) -> Void
) {
    // ... 初始化 asset、reader、writer ...

    switch mode {
    case .interpolation(let multiplier):
        // 走现有 RIFE Lite 补帧逻辑
        runInterpolation(multiplier: multiplier)

    case .superResolution:
        // 走 PiperSR 独立超分逻辑
        runSuperResolution()
    }
}
```

4.2 超分模式管线（独立）

超分模式的管线非常直接，不含光流计算和插帧：

```
AVAssetReader 解码 → PiperSR 2x 超分 → AVAssetWriter 编码（保持原帧率）
```

注意：

· 帧率不变。如果输入是 30fps，输出也是 30fps。
· PTS 不变。直接沿用原始样本的时间戳，不需要重新计算。
· 不需要音频特殊处理。音频透传逻辑与现有方案完全一致（使用 AVMutableComposition 或独立 AVAssetReader）。

4.3 超分尺寸适配

PiperSR 的固定输入尺寸为 640×360。如果用户的视频分辨率不是这个尺寸，需要先缩放到 640×360，超分到 1280×720，再缩放到用户期望的分辨率（如 1920×1080）。

推荐策略：在 UI 上固定超分模式为 “720p 增强”，即输入 720p 视频，输出 1080p 视频。

· 如果输入 > 720p：提示“视频已经是高清，无需超分”。
· 如果输入 < 720p：先缩放到 640×360，超分到 1280×720，再缩放到 1080p。

6. 性能与发热预期

指标 补帧模式（RIFE Lite） 超分模式（PiperSR）
单帧推理耗时 ~30 ms ~22.5 ms
额外内存 ~100 MB ~50 MB
设备发热 较高（ANE + GPU 并行） 中等（纯 ANE）
A16 处理速度 近实时 快于实时
是否支持 4x 支持 仅 2x

优势：因为超分模式不需要同时运行 GPU 着色器和光流计算，发热和内存压力大幅降低，A14 及以上设备都能流畅运行。

9. 注意事项

1. 不要同时串联 RIFE 和 PiperSR。如果用户选择超分，就跳过补帧；如果选择补帧，就跳过超分。这能避免双重 AI 负载导致手机崩溃。
2. PiperSR 的输入尺寸是固定的 640×360，超出这个范围的视频需要先缩放，这会增加一次额外的图像处理，请在性能评估时计入。
3. 音频处理逻辑完全复用现有方案，不需要为超分模式单独开发音频管线。
4. 码率依然需要动态调整。虽然超分不改变帧率，但分辨率从 720p 提升到 1080p，数据量增加，输出码率应相应提高（如 1.5 倍），否则画质提升会被压缩抵消。
