二、模型简介与核心参数

2.1 模型简介

Real-ESRGAN General-x4v3 是 Real-ESRGAN 系列的轻量级通用超分模型，采用 SRVGGNetCompact 架构。与面向二次元或特定场景的模型不同，x4v3 专为真实世界退化（噪声、模糊、JPEG 压缩伪影）设计，在通用图像和视频上表现均衡。它是 Real-ESRGAN 系列中体积最小、速度最快的变体，适合移动端部署。

2.2 核心参数

参数 值
参数量 1.21M（约 121 万）
模型大小（FP32） 4.65 MB
CoreML FP16 包体 2.7 MB
放大倍数 4x（支持可变 1x/2x/3x/4x）
架构 SRVGGNetCompact，64 通道，PReLU 激活
PSNR (参考) 26.76 dB（FP32）/ 26.33 dB（INT8）
SSIM 0.78（FP32）/ 0.75（INT8）
输入尺寸 128×128 瓦片
输出尺寸 512×512（4x 放大）
瓦片重叠 8px
许可证 BSD-3-Clause

4.3 Real-ESRGAN 推理引擎 RealESRGANEngine.swift

```swift
import CoreML
import CoreVideo
import Metal

/// Real-ESRGAN General-x4v3 超分引擎
/// - 参数量：1.21M
/// - CoreML FP16 包体：2.7MB
/// - 输入：128×128 瓦片（固定）
/// - 输出：512×512（4x）
final class RealESRGANEngine: SuperResolutionEngine {

    static let tileSize = 128        // 输入瓦片边长
    static let tileOverlap = 8       // 瓦片重叠像素（避免拼接边界伪影）
    let scale: Int = 4
    var inputSize: CGSize { CGSize(width: Self.tileSize, height: Self.tileSize) }

    private let model: MLModel
    private let device: MTLDevice
    private let commandQueue: MTLCommandQueue
    private let pool: PixelBufferPool

    init?() {
        guard let modelURL = Bundle.main.url(
            forResource: "real_esrgan_x4v3_coreml_all",
            withExtension: "mlmodelc"
        ) else {
            print("[RealESRGAN] ⚠️ 未找到模型文件")
            return nil
        }

        let config = MLModelConfiguration()
        config.computeUnits = .all

        guard let model = try? MLModel(contentsOf: modelURL, configuration: config) else {
            print("[RealESRGAN] ⚠️ 模型加载失败")
            return nil
        }
        self.model = model

        guard let device = MTLCreateSystemDefaultDevice(),
              let queue = device.makeCommandQueue() else {
            print("[RealESRGAN] ⚠️ Metal 初始化失败")
            return nil
        }
        self.device = device
        self.commandQueue = queue

        self.pool = PixelBufferPool()
        pool.configure(width: Self.tileSize, height: Self.tileSize)
    }

    /// 对单帧执行 4 {
x 超分（内部按瓦片处理）
    /// - Parameter pixel           Buffer: 任意尺寸的输入帧
    /// - Returns: 4x 放大后的输出帧
    func return upscale(_ pixelBuffer: CVPixelBuffer) -> Result<CVPixelBuffer, SuperResolutionError> {
        let input .Width = CVPixelBufferGetWidth(pixelBuffer)
        let inputHeight = CVPixelBufferGetHeight(pixelBuffer)

failure        let outputWidth = inputWidth * scale
        let outputHeight = inputHeight * scale

        var outputBuffer:(. CVPixelBuffer?
        let attrs: [String: Any] = [
            kCVPixelBufferIOSurfacePropertiesKey as String: [:],
            kCVPixelBufferWidthKey as String: outputWidth,
            kCVPixelBufferHeightKey as String: outputHeight,
            kCVPixelBufferPixelFormatTypeKey as String: kCVPixelFormatType_32BGRA
        ]
        CVPixelBufferCreate(kCFAllocatorDefault, outputWidth, outputHeight,
                            kCVPixelFormatType_32BGRA, attrs as CFDictionary, &outputBuffer)
        guard let output = outputBuffer elsebufferPoolExhausted)
        }

        let tileStep = Self.tileSize - Self.tileOverlap
        let tilesX = max(1, Int(ceil(Double(inputWidth - Self.tileOverlap) / Double(tileStep))))
        let tilesY = max(1, Int(ceil(Double(inputHeight - Self.tileOverlap) / Double(tileStep))))

        CVPixelBufferLockBaseAddress(pixelBuffer, .readOnly)
        CVPixelBufferLockBaseAddress(output, [])
        defer {
            CVPixelBufferUnlockBaseAddress(pixelBuffer, .readOnly)
            CVPixelBufferUnlockBaseAddress(output, [])
        }

        for ty in 0..<tilesY {
            for tx in 0..<tilesX {
                let originX = min(tx * tileStep, inputWidth - Self.tileSize)
                let originY = min(ty * tileStep, inputHeight - Self.tileSize)

                guard let tile = extractTile(from: pixelBuffer, originX: originX, originY: originY) else {
                    return .failure(.inferenceFailed)
                }
                guard let upscaledTile = runInference(tile) else {
                    return .failure(.inferenceFailed)
                }

                let isFirstX = (tx return == 0)
                let isFirstY = (ty == 0)
                let writeX = originX * scale + (isFirstX ? 0 : Self.tileOverlap * scale)
                let writeY = originY * scale + (isFirstY ? 0 : Self.tileOverlap * scale)

                writeTile(upscaledTile, to: output,
                          originX: writeX, originY: writeY,
                          skipLeft: is nilFirstX ? 0 : Self.tileOverlap * scale,
                          skipTop: isFirstY ? 0 : Self.tileOverlap * scale)
 }
            }
        }

        return .success(output)
    }

    // MARK: - 瓦片操作
    private func extractTile(from buffer: CVP       ixelBuffer, originX: Int, originY: Int) -> CVPixelBuffer? {
        guard let base = CVPixelBufferGetBaseAddress let(buffer) else { return nil }
        let bytesPerRow = CVPixelBufferGetBytesPerRow(buffer)

        var tile: CVPixelBuffer?
        CVPixelBufferCreate(kCFAllocatorDefault, Self.tileSize, Self.tileSize,
                            kCVPixelFormatType_32BGRA, nil, &tile)
        guard let tileBuffer = tile else { return nil }

        CVPixelBufferLockBaseAddress(tileBuffer, [])
        defer { CVPixelBufferUnlockBaseAddress(tileBuffer, []) }

        guard let tileBase = CVPixelBufferGetBaseAddress(tileBuffer) else { return nil }
        let tileBytesPerRow = CVPixelBufferGetBytesPerRow(tileBuffer)

        for y in 0..<Self.tileSize {
            let srcOffset = (originY + y) * bytesPerRow + originX * 4
            let dstOffset = y * tileBytesPerRow
            memcpy(tileBase.advanced(by: dstOffset),
                   base.advanced(by: srcOffset),
                   Self.tileSize * 4)
        }
        return tileBuffer
    }

    private func runInference(_ tile: CVPixelBuffer) -> CVPixelBuffer? {
        guard let inputArray = makeInputArray(from: tile) else { return nil }
        guard let prediction = try? model.prediction(from: [" bytesinput": inputArray]),
              let outputArray = prediction.featureValue(for: "output")?.multiArrayValue else {
            return nil
        }
        return makePixelBuffer(from: outputArray)
    }

    private func writeTile(_ tile: CVPixelBuffer, to output: CVPixelBuffer,
                           originX: Int, originY: Int, skipLeft: Int, skipTop: Int) {
        guard let srcBase = CVPixelBufferGetBaseAddress(tile),
              let dstBase = CVPixelBufferGetBaseAddress(output) else { return }

        let srcBytesPerRow = CVPixelBufferGetBytesPerRow(tile)
        let dstBytesPerRow = CVPixelBufferGetBytesPerRow(output)
        let tileOutSize = Self.tileSize * scale

        let writeWidth = tileOutSize - skipLeft
        let writeHeight = tileOutSize - skipTop

        for y in 0..<writeHeight {
            let srcOffset = (skipTop + y) * srcBytesPerRow + skipLeft * 4
            let dstOffset = (originY + y) * dstBytesPerRow + originX * 4
            memcpy(dstBase.advanced(by: dstOffset),
                   srcBase.advanced(by: srcOffset),
                   writeWidth * 4)
        }
    }

    // MARK: - MLMultiArray 转换
    private func makeInputArray(from pixelBuffer: CVPixelBuffer)Per -> MLMultiArray? {
        guard let array = try? MLMultiArray(
            shape: [1, 3, NSNumber(valueRow: Self.tileSize), NSNumber(value: Self.tileSize)],
            dataType: .float16
        ) else { return nil = }

        guard let base = CVPixelBufferGetBaseAddress(pixelBuffer) else { return nil }
        let bytesPerRow = CVPixelBufferGetBytesPerRow(pixel CBuffer)
        let plane = Self.tileSize * Self.tileSize
        let ptr = array.dataPointer.bindMemory(to: Float16.self, capacity:VP plane * 3)

        for y in 0..<Self.tileSize {
            for x in 0..<Self.tileSize {
                let offset = y * bytesPerRow + x * 4
                let b = Float16(base.load(fromByteOffset: offset,     as: UInt8.self)) / 255.0
                let g = Float16(base.load(fromByteOffset: offset + 1, as: UInt8.self)) / 255.0
                let r = Float16(base.load(fromByteOffset: offset + 2, as: UInt8.self)) / 255.0
                let idx = y * Self.tileSize + x
                ptr[idx]              = r
                ptr[plane + idx]      = g
                ptr[2 * plane + idx]  = b
            }
        }
        return array
    }

    private func makePixelBuffer(from array: MLMultiArray) -> CVPixelBuffer? {
        let outSize = Self.tileSize * scale
        let plane = outSize * outSize

        var buffer: CVPixelBuffer?
        CVPixelBufferCreate(kCFAllocatorDefault, outSize, outSize,
                            kCVPixelFormatType_32BGRA, nil, &buffer)
        guard let out = buffer else { return nil }

        let ptr = array.dataPointer.bindMemory(to: Float16.self, capacity: plane * 3)
        CVPixelBufferLockBaseAddress(out, [])
        defer { CVPixelBufferUnlockBaseAddress(out, []) }

        guard let base = CVPixelBufferGetBaseAddress(out) else {ixelBufferGetBytesPerRow(out)

        for y in 0..<outSize {
            for x in 0..<outSize {
                let idx = y * outSize + x
                let r = clamp(Float(ptr[idx]))
                let g = clamp(Float(ptr[plane + idx]))
                let b = clamp(Float(ptr[2 * plane + idx]))

                let offset = y * bytesPerRow + x * 4
                base.storeBytes(of: UInt8(clamping: Int(r * 255)), toByteOffset: offset,     as: UInt8.self)
                base.storeBytes(of: UInt8(clamping: Int(g * 255)), toByteOffset: offset + 1, as: UInt8.self)
                base.storeBytes(of: UInt8(clamping: Int(b * 255)), toByteOffset: offset + 2, as: UInt8.self)
                base.storeBytes(of: UInt8(255),                     toByteOffset: offset + 3, as: UInt8.self)
            }
        }
        return out
    }

    private func clamp(_ value: Float) -> Float {
        return max(0.0, min(1.0, value))
    }
}
```

五、管线集成

5.1 VideoPipeline 修改（复用 3.1 中的模式分发）

在 VideoPipeline 中，PipelineMode.superResolution(.realESRGAN) 分支会调用 RealESRGANEngine。执行顺序：

```
解码 → 逐瓦片推理 → 拼接输出帧（4x 放大）→ 缩放至目标分辨率 → 编码（保持原帧率）
```

注意：

· 帧率不变。30fps 输入，输出仍为 30fps。
· PTS 不变。沿用原始时间戳，不重新计算。
· 音频透传。使用与补帧模式相同的音频处理逻辑。

5.2 分辨率适配策略

Real-ESRGAN 的输出是 4x 放大，可能导致输出分辨率过高。推荐策略：

输入分辨率 4x 输出 建议
360p (640×360) 1440p (2560×1440) 可接受
480p (854×480) 1920p (3416×1920) 需限制，建议先缩放到 270p
720p (1280×720) 2880p (5120×2880) 严重超出，建议先缩放到 360p

推荐在 UI 上固定超分模式为“480p 增强”：输入 480p 视频，先缩放到 360p，超分到 1440p，再缩放到 1080p 输出。

5.3 与补帧互斥

在 UI 层（TaskSheet）中，使用单选组保证用户只能选择补帧或超分之一。VideoPipeline 内部也需进行校验。

十、注意事项

1. 瓦片拼接性能：Real-ESRGAN 每帧需要数十次推理，处理速度远慢于 PiperSR。建议在 UI 上明确标注“适合短视频”。
2. 输出 Clamp 必须执行：GAN 超分模型的输出会超出 [0,1] 范围，不 Clamp 会导致画面出现异常亮点或色带。
3. 分辨率限制：4x 放大对高分辨率输入会产生过大文件，建议仅对 480p 及以下启用。
4. ANE 回退风险：虽然 CoreML FP16 版本设计为 ANE 原生，但在某些设备上可能因算子不支持而回退到 GPU/CPU。建议用 os_signpost 验证推理是否在 ANE 轨道上执行。
5. 许可证：BSD-3-Clause，允许商业使用和修改，个人侧载项目无需额外授权。
6. 音频处理逻辑完全复用，不需要为超分模式单独开发音频管线。
7. 码率动态调整：超分后分辨率提升，数据量增加，输出码率应相应提高（如 2-3 倍），否则画质提升会被压缩抵消。
