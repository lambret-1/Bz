iOS 视频增强工作台 · 视频编辑页面 UI 细纲（v2）

页面名称：项目详情页（ProjectDetailView）
页面角色：导入视频后的核心编辑页，单页完成预览→剪辑→增强→导出
导航：独立 fullScreenCover 包裹 NavigationStack，禁止共用首页导航栈
返回：左上角「‹ 返回」按钮 + 系统边缘左滑手势
背景：纯黑 #000000（深色模式）/ #F2F2F7（浅色模式）

7. 状态与数据流
════════════════════════════════════════════════════════════

本地 @State：
· currentTime: TimeInterval = 0（播放头，驱动进度条+分切位置）
· isPlaying: Bool = false
· selectedSegmentID: UUID? = nil

全局 AppState：
· currentProject: Project?（包含 segments / enhancement / exportSettings）
· undoStack: [[VideoSegment]]（最多20步）
· showExportSettings / isProcessing / toastMessage

编辑操作流（全部经 AppState）：
splitSegment(at:) → pushUndo → 切分生成两段+缩略图 → saveProjects → Toast
duplicateSegment(_:) → pushUndo → 插入副本 → saveProjects → Toast
deleteSegment(_:) → pushUndo → 删除 → saveProjects → Toast
undoSegmentEdit() → popUndo → 恢复 → saveProjects → Toast
