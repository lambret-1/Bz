2.1 视频编辑器 UI 设计规范（优化完整版）

项目：iOS 视频增强工作台（CF 分支）
系统要求：iOS 16.0+
设计基调：深色专业剪辑器风格，兼顾浅色模式适配
核心原则：任务前置选择、极简导出流程、非破坏性编辑、帧精确控制
文档版本：v2.0
最后更新：2026-10-16

三、模块 1：顶部栏（TopBar）

位置：屏幕最顶部，高度 56pt。

元素 规格 交互
[X] 关闭 24pt 图标，左侧，点击区 44×44 弹出「放弃编辑？」确认弹窗

[导出] 按钮 粉红 #FF2D55，高 40pt，宽 72pt，圆角 8pt 点击启动导出流程，导出中置灰并显示「处理中…」

任务与分辨率选择器显示逻辑：

· 初始状态：显示源视频分辨率（如 720P）。
· 选择任务后：显示最高优先级任务名（如 超分 1080P、补帧 60fps、画质增强）。
· 若未选任何任务：显示源视频分辨率。

关闭确认弹窗：

· 标题：放弃编辑？
· 按钮：[保存草稿并退出]、[放弃]（红色）、[取消]。

四、模块 2：预览区（PreviewArea）

位置：顶部栏下方，16:9 比例，撑满宽度。

元素 规格 交互
视频画面 黑底，居中，保持原始比例 单击切换播放/暂停
控制面板显隐 — 双击切换顶部栏与底部工具栏的显隐
全屏 — 通过播放控制条右侧 ⛶ 进入

说明：不使用双击全屏，避免与单击暂停产生手势冲突。

五、模块 3：播放控制条（PlaybackControlBar）

位置：预览区下方，高度 48pt。

元素 规格 交互
时间码 等宽字体，左侧 点击切换「时间码」与「帧号」显示
播放/暂停 32pt 图标，居中 切换播放状态
撤销/重做 24pt 图标 无历史时置灰
全屏 24pt 图标 进入全屏预览

时间码显示格式：

· 时间码模式：00:01.500 / 00:06.000
· 帧号模式：f045 / f180（加粗，accent 色），右侧显示 40×40pt 当前帧缩略图。

逐帧微调区（仅 L2/L3 缩放级别显示）：

· 位置：播放按钮两侧。
· 左侧：◀ 上一帧，右侧：下一帧 ▶。
· 点击移动 1 帧，长按连续移动（每秒 10 帧）。
· 触觉反馈：UISelectionFeedbackGenerator。

六、模块 4：时间线（TimelineView）

位置：播放控制条下方，占据剩余空间。

6.1 刻度尺（Ruler）

属性 规格
高度 24pt
刻度间隔 随缩放级别动态调整
L0 每 5 秒一个刻度
L1 每 1 秒一个刻度
L2 每 0.2 秒一个刻度
L3 每帧一个刻度（标注帧号）
文字 caption，灰色

6.2 胶片轨道（Filmstrip）

属性 规格
高度 80pt
滚动 横向 ScrollView
总长度 视频总帧数 × 单帧宽度
缩略图 按可见范围动态渲染，滑出屏幕自动回收
播放头 固定在屏幕正中央，白色 2pt 竖线

缩略图宽度随缩放级别变化：

级别 单帧宽度 单屏可见帧数
L0 宏观 0.5pt 约 780 帧
L1 中观 2pt 约 195 帧
L2 微观 10pt 约 39 帧
L3 逐帧 20pt 约 19 帧

6.3 缩放体系

交互 行为
双指捏合 以双指中心为锚点缩放，同步调整 contentOffset
双击时间线 在 L1 与 L3 间切换
缩放滑块 辅助调节，位于刻度尺右侧

6.4 播放头吸附

· L2/L3 级别下，滚动停止后延迟 50ms，播放头平滑吸附到最近帧边界。
· 吸附时有轻微弹性动画，并触发 UISelectionFeedbackGenerator。

6.5 片段编辑交互

片段卡片：

· 时长标签：右下角，caption，白色文字，半透明黑底。
· 选中态：2pt accent 边框。
· 长按：进入拖动排序模式。

拖拽裁剪（Trim）：

· 每个片段左右两端显示可拖拽把手。
· 把手规格：宽 12pt，高 60pt，圆角 4pt，accent 色。
· 拖拽时：把手放大 1.2 倍，并显示当前帧缩略图预览气泡（80×45pt）。
· 边界检测：片段时长 < 0.05s 时，把手变红，阻止继续拖拽。

编辑操作：

操作 图标 说明
分割 剪刀 在播放头位置切分片段
复制 文档 复制选中片段并插入后方
删除 垃圾桶 删除选中片段，至少保留 1 个
撤销 箭头回退 有历史记录时高亮
重做 箭头前进 有重做记录时高亮

6.6 音频轨

入口：时间线下方，[+ 添加音频] 宽按钮，高 44pt，深灰背景。

音频片段：

· 高度：44pt。
· 背景：bgTertiary，圆角 4pt。
· 波形：accent 色，透明度 0.7，高度随音量变化。
· 选中态：2pt accent 边框。
· 拖拽把手：与视频片段一致，支持调整时间偏移。
· 支持分割与删除。

6.7 转场效果

位置：两个片段连接处，24pt 圆形按钮。

元素 规格
图标 square.on.square，12pt
默认态 灰色
激活态 accent 色
点击 弹出转场设置 Sheet

转场设置：

· 类型：无 / 淡入淡出 / 交叉溶解。
· 时长：0.1s – 1.0s Slider（步长 0.1s）。

6.8 短片段边界规则

当胶片总宽度 < 屏幕宽度时：

· 内容左对齐。
· 播放头允许偏离中心。
· 禁用惯性滚动，改为吸附拖拽。
· 避免出现大片空白。

九、模块 7：导出流程

9.1 导出前检查

· 检查磁盘空间：预估输出大小 > 剩余空间时，弹出「存储空间不足」Alert。
· Alert 内容：
  · 标题：存储空间不足
  · 消息：需约 XX MB，当前剩余 XX MB。请清理空间后重试。
  · 按钮：[清理缓存]（accent）、[取消]。

9.2 导出 HUD

位置：全屏半透明黑底覆盖。

```
┌──────────────────────────────────────┐
│                                      │
│           ╭───────╮                  │
│          ╱         ╲                 │
│         │    45%    │                │  ← 160pt 环形进度
│          ╲         ╱                 │
│           ╰───────╯                  │
│                                      │
│         正在超分处理...               │  ← headline
│         预计剩余 1 分 20 秒           │  ← subheadline
│                                      │
│            [ 取消 ]                  │  ← 44pt 圆形按钮
│                                      │
└──────────────────────────────────────┘
```

规格：

· 环形进度：160pt，线宽 8pt，accent → 橙色渐变。
· 中心：百分比 mono 32pt。
· 阶段文字：headline。
· 剩余时间：subheadline，灰色。
· 取消按钮：120×44pt，圆角 22pt。

取消行为：立即中断处理，返回编辑器，保留全部编辑状态。

十、模块 8：健壮性

10.1 草稿自动保存

触发时机：

· 每次编辑操作（分割/删除/拖动/改任务）。
· 定时每 10 秒。

视觉反馈：

· 在 TopBar 下方短暂显示 Toast，1.5 秒后消失。
· 内容：✅ 草稿已保存，caption 字号，bgSecondary 背景，圆角 16pt。

恢复逻辑：

· App 重启时检测草稿，弹出提示：「恢复上次编辑？[恢复] [重新开始]」。

十二、交互流程总览

12.1 首次进入

```
首页（空状态）
  → 点击「导入视频」
  → PHPicker 选择视频
  → 创建项目，进入编辑器
  → 顶部选择器显示源视频分辨率（如 720P）
```

12.2 编辑流程

```
编辑器
  → 左右滑动时间线，播放头定位
  → 双指捏合缩放至逐帧级别
  → 点击「分割」切分片段
  → 拖动裁剪把手微调
  → 长按片段拖动排序
  → 点击「复制」/「删除」
```

12.3 任务选择流程

```
编辑器
  → 点击顶部选择器
  → 弹出 TaskSheet
  → 选择增强任务（补帧 / 超分）
  → 选择分辨率、帧率、码率
  → 点击「应用设置」
  → 顶部选择器更新为任务名
```

12.4 导出流程

```
编辑器
  → 点击「导出」
  → 检查磁盘空间
  → 启动 ExportHUD
  → 后台处理（解码 → 增强 → 编码）
  → 处理完成
  → 进入结果页
  → 点击「保存到相册」
  → Toast 提示成功
```

十三、关键约束汇总

1. 预览区强制黑色，不受浅色模式影响。
2. 任务选择器显示源分辨率或当前任务名。
3. 补帧与超分从交互上互斥（单选组）。
4. 导出按钮不弹出设置面板，直接执行当前任务。
5. 时间线总长度 = 视频总帧数，L3 逐帧级别每帧宽 20pt。
6. 播放头固定在屏幕正中央，内容滚动。
7. 片段编辑支持分割、复制、删除、拖动排序、拖拽裁剪。
8. 导出 HUD 提供取消按钮，取消后保留编辑状态。
9. 处理完成后不静默保存，用户确认后再保存到相册。
10. 草稿自动保存，重启后可恢复。
11. 所有交互元素支持 VoiceOver。
12. 浅色模式下 TopBar 与 BottomToolbar 适配，预览区保持黑色。
