三、模块 1：顶部栏（TopBar）

位置：屏幕最顶部，高度 56pt。

· [X] 关闭按钮：左侧，24pt 图标。点击弹出「放弃编辑？」确认弹窗（含「保存草稿并退出」「放弃」「取消」）。
· [任务与分辨率选择器 ▼]：右侧，深灰圆角矩形（高 32pt，圆角 6pt）。
  · 显示逻辑：
    · 初始显示源视频分辨率（如 720P）。
    · 选择任务后更新为最高优先级任务（如 超分 1080P、补帧 60fps、画质增强）。
  · 点击交互：弹出「任务选择 Sheet」。
· [导出] 按钮：最右侧，粉红色圆角矩形（高 40pt，宽 72pt，圆角 8pt）。
  · 点击后：按钮变灰，显示 处理中…，启动导出 HUD，禁用所有编辑操作。

四、模块 2：预览区（PreviewArea）

位置：顶部栏下方。

· 视频画面：黑底，居中，保持原始比例。
· 交互：
  · 单击：播放/暂停（避免与双击冲突）。
  · 双击：切换控制面板（顶部栏+底部工具栏）的显隐。
· 全屏：通过播放控制条右侧的 ⛶ 按钮进入，不使用双击。

五、模块 3：播放控制条（PlaybackControlBar）

位置：预览区下方，高度 48pt。

· 时间码：左侧，等宽字体，格式 00:01 / 00:06。点击可切换为帧号 f045 / f180。建议同时显示（如 00:01.500 · f045）。
· 播放/暂停按钮：正中央，32pt 图标。
· 右侧操作组：撤销（↶）、重做（↷）、全屏（⛶）。
· 逐帧微调区（仅当缩放级别为 L2/L3 时显示）：
  · 播放按钮两侧显示 ◀ 上一帧 / 下一帧 ▶。
  · 每次点击移动 1 帧，伴随 UISelectionFeedbackGenerator 触觉反馈。
  · 强制联动：点击逐帧按钮时，若当前缩放级别低于 L3，自动将时间线缩放至 L3，确保用户能看到帧位移。

六、模块 4：时间线（TimelineView）

位置：播放控制条下方，占据剩余空间。

6.1 刻度尺（Ruler）

· 高度 24pt，根据缩放级别动态显示刻度。
· L0 显示分钟，L3 显示帧号（f01, f02）。

6.2 胶片轨道（Filmstrip）

· 高度 80pt，横向 ScrollView。
· 总长度 = 视频总帧数，绝不截断。
· 播放头：固定在屏幕正中央的白色 2pt 竖线。滑动时播放头不动，内容滚动。
· 缩略图：按可见范围动态渲染，L3 逐帧下每帧宽 20pt，单屏约 19 帧。
· 吸附效果：在 L2/L3 级别下，滑动停止后播放头自动吸附到最近帧边界（避免与滚动惯性冲突，使用 scrollTargetBehavior 或延迟计算）。

6.3 时间线缩放体系

· 双指捏合：以双指中心点为锚点缩放，同时调整 contentOffset，保证缩放后关注点不偏移。
· 双击时间线：在 L1 与 L3 之间快速切换。
· 4 档缩放：
  · L0（宏观）：单帧 0.5pt
  · L1（中观）：单帧 2pt
  · L2（微观）：单帧 10pt
  · L3（逐帧）：单帧 20pt

6.4 短片段边界规则（新增）

· 当时间线总宽度 < 屏幕宽度时：内容左对齐，播放头允许偏离中心，或禁用惯性滚动改为吸附拖拽，避免出现大片空白。

6.5 片段编辑交互（新增）

· 拖拽裁剪（Trim）：每个片段左右两端增加可拖拽把手。拖拽时实时预览画面，播放头自动吸附到帧边界。
· 分割：在播放头位置切分片段。
· 删除：删除选中片段，至少保留 1 个片段。
· 复制：复制选中片段并插入到后方。

6.6 音频轨（新增）

· 时间线下方预留音频轨道层。
· 导入音频后，显示波形图条，支持拖拽调整时间偏移。
· 音频片段支持分割与删除。

6.7 末尾 [+] 按钮

· 轨道最右侧，白色方形圆角按钮，点击添加媒体。

位置：点击顶部选择器后弹出的 Modal Sheet。

布局结构：

1. 顶部：标题「选择处理任务」，右上角 [取消]。

   · 帧率（下拉）
   · 码率（下拉）
3. AI 画质增强区（单选组替代互斥 Toggle）：
   ```
   [ 不增强 ] [ 智能补帧 ] [ 超清修复 ]
   ```
   · 选中「智能补帧」→ 显示倍数选项 [2x] [4x]

九、模块 7：导出与结果流程

9.1 导出前检查（新增）

· 检查存储空间：预估输出大小 > 剩余空间，弹出警告，阻止导出。
· 检查片段合法性：segments 不为空。

9.2 导出 HUD

· 半透明黑底覆盖。
· 显示内容：
  · 环形进度（唯一一个进度条）。
  · 当前阶段文字（如「正在超分处理…」）。
  · 百分比。
  · 预计剩余时间。
· 提供 [取消] 按钮，取消后回到编辑器，保留编辑状态。

9.3 结果确认页（替代静默保存）

· 处理完成后，进入结果页，不静默保存到相册。
· 页面内容：
  · 视频预览器。
  · 对比信息（原始 vs 输出）。
  · 操作按钮：[保存到相册] [分享] [返回编辑器]。
· 用户确认保存后，调用 PHPhotoLibrary 保存，并弹出 Toast「✅ 已保存到相册」。

---

十、边缘场景与容错（新增）

10.1 草稿自动保存

· 每次编辑操作（分割/删除/拖动/改任务）后，静默将 segments 与任务状态保存到本地。
· 重新打开 App 时，若有未处理草稿，弹出「恢复上次编辑？[恢复] [重新开始]」。

10.2 浅色模式适配

· 全 App 跟随系统浅色/深色模式。
· 仅预览区强制黑色，其余面板适配浅色背景与深色文字。

10.3 内存与热状态

· 过热时：HUD 显示警告「设备温度较高，建议暂停」，提供暂停/继续按钮，不自动修改用户参数。
· 内存警告：临时的 reduceInputSize() 降级，处理结束后恢复。

10.4 无障碍支持

· 所有按钮、时间线、播放头添加 accessibilityLabel 和 accessibilityHint。
· 播放头：读出「当前位于第 45 帧，共 180 帧」。

---

十一、开发落地优先级建议

1. 第一步（骨架）：静态布局（顶部栏、预览区、播放条、底部工具栏），底部用「复制」替代「动画」。
2. 第二步（时间线）：ScrollView 平铺色块，实现播放头居中与惯性滚动。
3. 第三步（逐帧与边界）：实现 L0-L3 缩放，处理短片段边界，加入逐帧按钮与自动放大联动。
4. 第四步（任务 Sheet）：实现单选互斥逻辑与顶部选择器文字更新。
5. 第五步（导出闭环）：实现 HUD（含取消与阶段显示），结果页与相册保存。
6. 第六步（健壮性）：接入草稿自动保存、浅色模式、无障碍标签。

```swift
struct SegmentTrimOverlay: View {
    @State private var leftDragging = false
    @State private var rightDragging = false
    let segment: VideoSegment
    let onTrim: (TimeInterval, TimeInterval) -> Void

    var body: some View {
        HStack(spacing: 0) {
            TrimHandle(isDragging: leftDragging, isAtBoundary: segment.duration < 0.05)
                .gesture(
                    DragGesture()
                        .onChanged { _ in leftDragging = true }
                        .onEnded { value in
                            leftDragging = false
                            let delta = value.translation.width / 20.0
                            let newStart = max(0, segment.sourceStart + delta)
                            onTrim(newStart, segment.sourceEnd)
                        }
                )

            TrimHandle(isDragging: rightDragging, isAtBoundary: segment.duration < 0.05)
                .gesture(
                    DragGesture()
                        .onChanged { _ in rightDragging = true }
                        .onEnded { value in
                            rightDragging = false
                            let delta = value.translation.width / 20.0
                            let newEnd = segment.sourceEnd + delta
                            onTrim(segment.sourceStart, newEnd)
                        }
                )
        }
        .frame(height: 80)
    }
}
```

补充 2：音频轨的波形可视化

UI 规格

属性 值
波形高度 40pt
波形颜色 accent 色，透明度 0.7
背景色 bgTertiary
选中态边框 2pt accent 色
拖拽把手 与视频片段一致
时间偏移 支持水平拖拽

Swift 代码

```swift
import SwiftUI
import AVFoundation

struct AudioWaveformView: View {
    let url: URL
    let duration: TimeInterval
    let color: Color

    @State private var samples: [Float] = []

    var body: some View {
        GeometryReader { geometry in
            HStack(spacing: 1) {
                ForEach(Array(samples.enumerated()), id: \.offset) { _, sample in
                    let barHeight = max(2, CGFloat(sample) * geometry.size.height)
                    RoundedRectangle(cornerRadius: 1)
                        .fill(color.opacity(0.7))
                        .frame(width: 2, height: barHeight)
                }
            }
            .frame(maxHeight: .infinity, alignment: .center)
        }
        .onAppear {
            loadWaveform()
        }
    }

    private func loadWaveform() {
        // 简化实现：从音频文件读取波形样本
        // 实际项目中可使用 Accelerate 框架加速
        guard let file = try? AVAudioFile(forReading: url) else { return }
        let format = file.processingFormat
        let frameCount = UInt32(file.length)
        guard let buffer = AVAudioPCMBuffer(pcmFormat: format, frameCapacity: frameCount) else { return }
        try? file.read(into: buffer)

        guard let channelData = buffer.floatChannelData else { return }
        let samplesPerPixel = Int(frameCount) / 200
        var result: [Float] = []

        for i in stride(from: 0, to: Int(frameCount), by: samplesPerPixel) {
            var maxValue: Float = 0
            for j in 0..<samplesPerPixel {
                if i + j < Int(frameCount) {
                    maxValue = max(maxValue, abs(channelData[0][i + j]))
                }
            }
            result.append(maxValue)
        }
        samples = result
    }
}

struct AudioTrackView: View {
    let audioSegment: AudioSegment
    let isSelected: Bool

    var body: some View {
        HStack(spacing: 0) {
            RoundedRectangle(cornerRadius: 4)
                .fill(Color(uiColor: .tertiarySystemBackground))

                .overlay(

                .padding(.horizontal, 4)

    }
}

}
```

```swift
import SwiftUI

struct StorageAlertModifier: ViewModifier {
    @Binding var isPresented: Bool
    let requiredMB: Int
    let availableMB: Int
    let onCleanCache: () -> Void

    func body(content: Content) -> some View {
        content
            .alert("存储空间不足", isPresented: $isPresented) {
                Button("清理缓存") { onCleanCache() }
                Button("取消", role: .cancel) {}
            } message: {
                Text("需约 \(requiredMB) MB，当前剩余 \(availableMB) MB。请清理空间后重试。")
            }
    }
}

extension View {
    func storageAlert(
        isPresented: Binding<Bool>,
        requiredMB: Int,
        availableMB: Int,
        onCleanCache: @escaping () -> Void
    ) -> some View {
        modifier(StorageAlertModifier(
            isPresented: isPresented,
            requiredMB: requiredMB,
            availableMB: availableMB,
            onCleanCache: onCleanCache
        ))
    }
}
```

补充 8：帧精确编辑的帧号显示

UI 规格

· L3 逐帧模式下：
  · 时间码区域显示：f045 / f180，字体加粗，accent 色。
  · 右侧显示当前帧缩略图预览（40×40pt，圆角 4pt）。
· 非 L3 模式下：
  · 显示标准时间码 00:01.500 / 00:06.000。

Swift 代码

```swift
import SwiftUI

struct TimecodeDisplay: View {
    let currentFrame: Int
    let totalFrames: Int
    let currentTime: TimeInterval
    let totalTime: TimeInterval
    let isFrameMode: Bool
    let thumbnail: UIImage?

    var body: some View {
        HStack(spacing: 8) {
            if isFrameMode {
                Text("f\(String(format: "%03d", currentFrame)) / f\(String(format: "%03d", totalFrames))")
                    .font(.system(size: 14, weight: .bold, design: .monospaced))
                    .foregroundColor(Color(red: 1.0, green: 0.18, blue: 0.33))

                if let thumbnail {
                    Image(uiImage: thumbnail)
                        .resizable()
                        .scaledToFill()
                        .frame(width: 40, height: 40)
                        .cornerRadius(4)
                        .clipped()
                }
            } else {
                Text(formatTime(currentTime) + " / " + formatTime(totalTime))
                    .font(.system(size: 14, design: .monospaced))
                    .foregroundColor(.white)
            }
        }
    }

    private func formatTime(_ time: TimeInterval) -> String {
        let minutes = Int(time) / 60
        let seconds = Int(time) % 60
        let ms = Int((time - floor(time)) * 1000)
        return String(format: "%02d:%02d.%03d", minutes, seconds, ms)
    }
}
```
