iOS 视频增强工作台

项目定位：端侧视频增强与轻量剪辑工具，专注「导入 → 剪辑 → 增强 → 导出」闭环。
开发分支：CF
最低系统：iOS 16.0
开发环境：GitHub Actions macOS Runner（无需本地 Mac）
分发方式：未签名 IPA，AltStore / SideStore / TrollStore 侧载
不上架 App Store，不使用 TestFlight

---

项目简介

主界面为专业剪辑器布局，支持时间线缩放与逐帧编辑；补帧、超分、清晰度增强等 AI 能力收进「任务选择器 + 导出」流程，导出时直接执行，不弹设置面板。

⚠️ 当前 UI 已不再适用。原卡片式参数设置界面已被废弃，改为对标专业短视频剪辑器的全新布局。UI 改造是当前开发重点。

---

核心能力

· 补帧：RIFE Lite，2x / 4x，提升流畅度
· 超分：PiperSR 2x / Real-ESRGAN 4x，提升分辨率
· 清晰度增强：自适应锐化、双边滤波降噪、对比度/色彩微调
· 音频处理：动态容器选择与音频透传/重编码
· 基础编辑：分切、复制、删除、拖动排序、拖拽裁剪，支持逐帧精确操作
· 导出优化：HEVC 编码 + 动态码率 + 动态容器

---

关键约束

1. 最低支持 iOS 16.0，全部使用 iOS 16+ 异步 API
2. 无本地 Mac，构建全部在 GitHub Actions 完成
3. 不上架 App Store，仅侧载分发
4. 无设备分级：不写死芯片型号，不自动限制分辨率或倍数
5. 补帧与超分互斥，不可同时使用
6. 原始视频文件永不修改，编辑仅修改 segments 数组
7. 时间线至少保留 1 个片段
8. 清晰度增强顺序固定：降噪 → 超分/补帧 → 缩放 → 锐化 → 对比度
9. 音频策略：PCM → MOV 透传，AAC → MP4 透传，其他 → MP4 + AAC 重编码
10. 长视频按 30 秒分段处理，单 AVAssetWriter 连续写入
11. 热降级仅提示用户，不自动更改参数
12. 预览区强制黑色，不受浅色模式影响

```
├── 预览区：AV Player 预览
├── 播放控制条：时间码/帧号、播放、撤销/重做
├── 节时间线：刻度尺、胶片、播放头 |
、缩放、逐帧、片段编辑、音频轨
└── 底部工具栏：收起、分割、变速、音量|、复制、删除、AI音效
```

时间线缩放体系：

级别 单帧宽度 用途
L0 宏观 0.5pt 全局浏览
L1 中观 2pt 常规剪辑
L2 微观 10pt 精细调整
L3 逐帧 20pt 帧精确编辑

任务与导出核心逻辑：

· 点击顶部胶囊 → 弹出 TaskSheet 选择任务。
· 点击「导出」→ 直接执行选中任务，不弹设置面板。
· 处理完成后进入结果页，用户确认后再保存到相册。
