# iOS 视频增强工作台 · 项目总纲与开发路线图

## 1. 项目概述
- **定位**：端侧视频增强与轻量剪辑工具
- **最低系统**：iOS 16.0
- **开发环境**：GitHub Actions macOS Runner
- **分发方式**：未签名 IPA 侧载（AltStore / SideStore / TrollStore）

## 3. 核心功能矩阵
| 类别 | 功能 | 技术方案 |
| :--- | :--- | :--- |
| 流畅度 | 补帧 2x / 4x | RIFE Lite |
| 分辨率 | 超分 2x | PiperSR |
| 分辨率 | 超分 4x | Real-ESRGAN x4v3 |
| 清晰度 | 锐化 / 降噪 / 对比度 | Metal Shader |
| 音频 | 音频修复/透传 | AVFoundation |
| 编辑 | 分切/复制/删除/排序/逐帧 | SwiftUI 时间线 |
| 导出 | HEVC + 动态码率 | AVAssetWriter |

## 4. UI 架构核心逻辑
- 主界面 = 专业剪辑器（时间线 + 播放头 + 逐帧缩放）。
- 任务选择 = 顶部胶囊（前置选择）。
- 导出 = 点击后直接执行，不弹设置面板。
- 补帧与超分 = 互斥，单选组保证。
- 无设备分级 = 所有参数由用户手动选择。

## 6. 分支与工程结构
- **开发分支**：CF
- **工程路径**：
  - `Features/Editor/`：编辑器 UI
  - `Core/Pipeline/`：管线与模式分发
  - `Core/SuperResolution/`：超分引擎
  - `Resources/`：模型文件（通过 Git LFS）

## 7. 关键约束
1. 预览区强制黑色，不受浅色模式影响。
2. 补帧与超分从交互上互斥。
3. 时间线总长度 = 视频总帧数。
4. 处理完成后，用户确认再保存到相册。
5. 草稿自动保存，重启后可恢复。
6. 不上架 App Store，侧载分发。
